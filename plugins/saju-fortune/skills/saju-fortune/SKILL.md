# 사주·명리·점성·운세·토정·밥그릇

사용자가 사주, 명리, 점성, 일/월/연 운세, 토정비결, **밥그릇·소비약점**을 물으면 이 스킬을 쓴다. 숫자(전화번호 등)만이면 `numerology-meaning`을 쓴다.

## 공통 규칙

- 한국어로 짧게. 점술 확정·수익 보장·중요 의사결정 근거로 권하지 않는다.
- 결론을 먼저, 이유 한 줄. 필요 시 question widget.
- 출생 정보: 생년월일(필수), 양력/음력, 출생 시각·성별·출생지(있으면 정확도↑). 없으면 필수만 한 번 묻는다. 사용자가 저장하라고 하면 메모리에 남긴다.
- 자시라면 **23시대(야자)**와 **0시 이후(조자)**를 반드시 구분한다.
- 표·원전이 있으면 따르고, 없으면 전통 프레임으로 요약한 뒤 「간이 해석」임을 밝힌다. 없는 고전 구절을 지어내지 않는다.
- 한자는 출력에 쓰지 않는다(내부 계산은 가능).

## 입력 템플릿 (밥그릇·소비약점 등)

- 생년월일: {예: 1982년 2월 18일}
- 양력/음력: {양력/음력}
- 출생시간: {예: 0시 이후 자시 / 사시}
- 성별: {남/여}

메모리에 출생정보가 있으면 그대로 쓰고, 시각이 후보 둘이면 widget으로 한 번만 고르게 한다.

## (B) 사주·명리

1. 생년월일(+시)로 사주팔자(년월일시 간지)를 산출한다. 절기 기준(만세력)을 쓰고, 시각 없으면 일주 중심·시주 미상으로 표시한다.
2. 일간·오행 개수·신강/신약 요지·용신 후보를 짧게.
3. 요청 시 대운·세운(해당 연)만. 장문 풀이·평생사 단정 금지.

## (B2) 밥그릇·소비약점

「밥그릇」「소비 약점」「왜 돈이 새는지」 등 요청, 또는 위 입력 템플릿으로 밥벌이·소비 분석을 시키면 이 섹션만 쓴다.

### 분석

생년월일시로 사주를 계산한 뒤 아래만 짧고 쉽게 정리한다. **계산 과정·신살 전체 나열은 출력하지 않는다.**

#### 1. 밥그릇 (3가지만)

- 식신: 재능·실무·경험을 결과물·밥벌이로 연결하는 힘
- 인성: 배움·지식·기술·문서·자격·전문성이 밥벌이에 도움이 되는 힘
- 천을귀인: 원국에서 사람 도움·귀인운을 상징하는 요소 여부

각 항목 판정: `강함` / `있음` / `약함` / `없음` / `조건부`(천을귀인은 주로 있음·없음·조건부)

과장 금지: 「평생 굶지 않는다」「무조건 돈을 번다」 같은 단정 금지.

#### 2. 소비 약점 (TOP 3만)

원국에서 실제로 해당하는 신살·조합만 보고 **가장 강한 소비 약점 3개**만 뽑는다. 신살 이름 장황 설명 금지.

핵심: 소비 **품목**보다 **왜 쓰는지(심리·명분)**.

예시 카테고리(해당할 때만 사용):
- 배움·자기계발 — 「나한테 도움이 된다」면 지출 기준이 느슨해짐
- 이동·새로운 시작 — 「어차피 할 거니까」로 시작 비용을 밀어붙임
- 대접·주도하는 자리 — 「이 정도는 내가 해야지」가 반복되면 커짐
- 먹는 것·생활 만족 — 맛·좋은 것·가까운 사람과 누리는 생활은 아끼지 않음
- 체면·좋은 물건 — 한번 살 거면 좋은 것을,로 예상보다 커짐
- 계획·약속 — 「하기로 했으니까」로 계속 씀

항목당 2~3문장. 「여행에 돈 쓴다」「책에 돈 쓴다」처럼 품목만 쓰지 말 것.
학파에 따라 달라질 때만 짧게 주석.

### 출력 포맷 (그대로)

```
밥그릇

- 식신: {강함/있음/약함/없음} — {한 줄 해석}
- 인성: {강함/있음/약함/없음} — {한 줄 해석}
- 천을귀인: {있음/없음/조건부} — {한 줄 해석}

소비 약점

1. {이름} — {평소 성향 + 돈을 쓰게 되는 심리}. {상황·예시}.
2. {이름} — …
3. {이름} — …

한 줄 결론

{어떤 힘으로 먹고사는지}, 그리고 “{대표 심리 3개}” 때문에 새는 돈을 조심하면 된다.
```

## (C) 점성(요청 시)

출생 일시·장소로 태양 별자리 등 간이 요약. 「상승·정확한 하우스」는 시각·장소 있을 때만. 서양 점성과 사주를 섞어 하나의 「진실」로 포장하지 않는다.

## (D) 운세·토정비결

- **운세**: 묻은 기간(오늘/이번 주/이번 달/올해) + 사주 세운 또는 일운 프레임으로 총운·주의점 3줄 이내.
- **토정비결**: 요청 연도의 세운을 토정 전통 프레임(수·괘 요지)으로 짧게. 원문 수번호가 확정되면 번호를 밝히고, 불확실하면 「간이」로 표시. 없는 수 내용을 창작하지 않는다.

## 일반 출력 골격 (B2 제외)

1. 한 줄 결론
2. 근거(간지/오행/기간)
3. 참고·한계 한 줄

숫자 수리와 같이 오면 수리는 `numerology-meaning`으로 따로, 사주·밥그릇은 이 스킬로 구분해 쓴다.

## 계산 스크립트 (간이)

간지·식신·인성·천을귀인은 `scripts/saju_calc.py`로 먼저 산출하고, 출력의 근거를 B2 포맷으로만 옮긴다(계산 과정은 사용자에게 보이지 않는다).

```bash
pip install sxtwl
python3 scripts/saju_calc.py 1990-05-15 14:30            # 양력, 일반 시각
python3 scripts/saju_calc.py 1990-05-15 00:35            # 0시 이후 자시(조자)
python3 scripts/saju_calc.py 1990-05-15 23:30 --zi ya    # 23시대 자시(야자)
```

- 양력만 입력받는다. 음력이면 먼저 양력으로 바꾼다.
- 천을귀인 표는 학파별로 다를 수 있어 결과는 「간이」로 말한다.
- 식신·인성은 천간과 지장간까지 본다.
